## 三网直连到底指什么

三网直连指电信、联通、移动三家回程都走优化路径回国，不是“三网都能 ping 通”。CN2 是中国电信的第二代承载网，CN2 GT 走 163 骨干，价格低，晚高峰容易和普通流量一起挤；CN2 GIA 走独立轻载路径，跳数少，拥塞概率低。联通常见 AS4837、AS9929，移动常见 CMI、CMIN2。商家把“三网直连”写成一句话时，可能只是三家都能直连，不等于三家都走精品网。

这也是“三网直连 VPS”最容易买错的地方。商品名写三网直连，实际可能只有电信走 CN2，联通走 4837，移动走 CMI，回程再各自绕一下。判断真假不能看标题，要看回程路由和晚高峰丢包。CN2 GIA 也不是一个可以靠价格猜的属性，同样标“洛杉矶 CN2 GIA”的产品，上游资源和晚高峰表现能差出很多。

## 晚高峰怎么自测

销售页的“直连”两个字不能代替晚高峰测试。可执行的方法如下：

1. 向 Evoxt 支持要目标节点测试 IP。拿不到，就先买最低档月付，不要直接年付。
2. 在电信、联通、移动各找一台国内机器，北京时间 20:00 到 24:00 每小时 `ping` 一次，连续 6 小时。用 `mtr` 看回程经过哪些 AS。
3. 判断标准：平均延迟稳定在 200ms 内、丢包低于 1%，接近优质回国线；晚高峰延迟翻倍或丢包超过 5%，就是普通线路或拥塞线。
4. 同时下载 100MB 测试文件，看晚高峰能不能维持标称带宽的 50% 以上。香港节点重点看 30 到 50ms 是否稳定，美国节点看 150 到 200ms 是否稳定。

这套方法比看商家宣传图有用，也能帮你决定要不要续费。测试结果不稳定，就按月付用着，别用年付锁死。

## 下单前确认清单

1. 目标节点是香港 Premium 还是美国、欧洲标准节点。价格同档，流量和路由不同。
2. 月流量额度。香港同价套餐可能低于美国标准版，结算页看到多少就是多少。
3. 退款窗口和取消条件。官方价格页没写，必须开工单确认。
4. 测试 IP 和晚高峰路由。别等付款后才发现回程绕路。
5. 是否需要额外 IPv4，价格是 $3/月。
6. 是否需要 IPv6。公开测评的洛杉矶 VM-1 有 1 个 IPv6，但下单页要确认所选套餐是否含。
